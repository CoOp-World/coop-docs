# Legacy Game Text (Hebrew)

> **Status: legacy inventory (Oct 2024).** Every sentence in the original Hebrew game, migrated from Notion. Texts may since have changed in the client (see `src/consts/Texts.js` and the i18next resources). Use it as a reference for wording and for which lines had voice-over.

Markers: **טקסט** = on-screen text; **דיבוב** = voice-over recording. Sections are split by the virtual character and the player's gender (זכר = male, נקבה = female). The virtual characters are Ilan (אילן) and Bar (בר).

## Game rules visible in the text (verify against the code)

- Helping costs the helper: the human gives up **5 coins**, the virtual player gives up **5 ice cubes**.
- A special coin is worth **10 regular coins**.
- The virtual player collects ice cubes; the text states it is not a competition, there are no winners or losers.
